# InfinityNow: Digital Fortress

Crea desde cero el sitio web corporativo oficial de una empresa de ciberseguridad llamada INFINITYNOW.

IMPORTANTE:
- El sitio debe verse como una empresa real de ciberseguridad B2B, profesional, madura y confiable.
- NO debe parecer una plantilla genérica de cybersecurity.
- NO utilizar estética gamer, hacker cliché, calaveras, código Matrix, exceso de circuitos, candados gigantes ni efectos visuales exagerados.
- La identidad visual debe transmitir: confianza, seguridad, tecnología, infraestructura, inteligencia y profesionalismo.
- Usa principalmente NEGRO, GRIS OSCURO, BLANCO y tonos muy sutiles de azul/cyan como color tecnológico de acento.
- Diseño moderno, premium, minimalista y corporativo.
- Prioriza legibilidad, jerarquía visual y experiencia de usuario.
- El sitio debe ser completamente responsive para desktop, tablet y móvil.

DISEÑO VISUAL

Utilizar:

- Fondo principal negro / #050505 o similar.
- Secciones alternando negro y gris extremadamente oscuro.
- Texto blanco.
- Texto secundario gris.
- Azul/cyan únicamente como acento.
- Bordes sutiles.
- Glassmorphism muy moderado.
- Sombras suaves.
- Gradientes discretos.
- Mucho espacio negativo.

Tipografía:
Utilizar una tipografía moderna y profesional tipo Inter, Manrope o similar.

Los títulos deben tener mucho peso visual.

Las animaciones deben ser:
- suaves
- rápidas
- profesionales
- no invasivas

Utilizar scroll reveal, hover states y pequeñas transiciones.

NO utilizar:
- parallax excesivo
- partículas excesivas
- efectos glitch
- lluvia de código
- calaveras
- hackers encapuchados
- imágenes cliché de cybersecurity
- animaciones que afecten el rendimiento

IMPORTANTE PARA DEPLOYMENT:

El proyecto debe ser compatible con GitHub Pages.

No utilizar funcionalidades que requieran un servidor Node.js en producción para renderizar la página.

La aplicación debe poder construirse mediante:

npm install
npm run build

El resultado de producción debe generarse correctamente en la carpeta dist.

No utilizar rutas que provoquen errores 404 al acceder directamente a una página desde GitHub Pages.

Inicialmente el sitio puede ser una Single Page Application con navegación mediante anchors/secciones.

NO implementar autenticación, base de datos ni backend todavía.

OBJETIVO FINAL:

El resultado debe parecer el sitio web de una empresa de ciberseguridad profesional que puede presentarse ante bancos, empresas financieras, entidades gubernamentales y empresas medianas/grandes.
